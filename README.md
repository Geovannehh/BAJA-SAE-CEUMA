# Baja SAE — Site separado

Estrutura organizada do site original:

- `index.html` — estrutura HTML
- `css/style.css` — estilos e responsividade
- `js/script.js` — interações, navegação, animações, modal e protótipo 3D
- `assets/` — imagens e PDF que estavam embutidos no HTML

## Como executar

Abra `index.html` no navegador.

Para desenvolvimento local, também pode usar o Live Server do VS Code.

## Observação

O conteúdo e a lógica do site foram preservados; a alteração principal foi retirar CSS, JavaScript e arquivos em Base64 de dentro do HTML e organizá-los em arquivos separados.
